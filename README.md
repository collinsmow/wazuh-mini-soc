# \# Wazuh Mini SOC



### Home SOC lab built with Wazuh SIEM. Attack simulation, detection engineering, and incident response write-ups.



\## Why I built this

I'm building toward an entry-level SOC analyst role. I hold the ISC2 CC

certification and practice on TryHackMe, and I wanted hands-on experience

with the full blue team workflow: collecting logs, detecting attacks,

triaging alerts, and tuning detections.



My main focus is alerting and tuning, so the right high-severity alerts

reach me quickly without drowning in noise.



\## Lab environment

\- Host: Windows laptop, i7-10870H, 32 GB RAM, VirtualBox

\- Wazuh 4.14 (all-in-one) on Ubuntu Server 22.04

\- Windows VM endpoint with Sysmon (SwiftOnSecurity config)

\- Planned: Linux endpoint and Kali attacker
